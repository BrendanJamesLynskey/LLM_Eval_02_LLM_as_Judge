# LLM_Eval_02_LLM_as_Judge

Deep dive into using language models as automated evaluators. Covers pairwise vs Likert scoring, rubric and exemplar-based judge prompts, chain-of-thought rationale extraction, and the four major biases (positional, verbosity, self-preference, sycophancy). Explains bias mitigation through randomisation, multi-judge ensembling, and bias correction; calibration workflows using ground-truth alignment; constitutional multi-criteria eval; and a cost vs quality comparison of Sonnet, Opus, and open-weight judge models.
